**给 DeepSeek Harness（dsh）用的本地随手笔记插件。** 每篇笔记就是一个 Markdown 文件，数据完全在你本机，不依赖任何云服务——想到什么记什么，聊完什么存什么。

> 🌱 本项目由 [fangqiing/dsh-knowledge-lite](https://github.com/fangqiing/dsh-knowledge-lite)（v0.1.6，MIT）深度改造而来：全新卡片式界面、自定义标签管理、平铺速览列表，并保留其全部核心能力（全文搜索、Markdown 预览、自动保存、附件抽取、对话回写）。感谢原作者的开源工作。

---

## ✨ 它解决什么问题

- **聊天里的知识点留不住？** 每轮对话结束后一键「存入随手笔记」，AI 自动抽取可复用的命令、配置、结论与坑，勾选后写入
- **笔记散落各处找不回？** 全文搜索 + 标签筛选，毫秒级命中
- **不想把笔记交给第三方云？** 每篇一个 `.md`，放在你指定的本地文件夹，用 VS Code / Obsidian / 记事本都能直接改，插件自动识别
- **文档里的内容没法问 AI？** 拖入 Office 文件自动零依赖抽取正文，笔记立即可搜索、可被 AI 引用

## 🎨 界面一览

- **卡片式双栏布局**：左侧速览列表 + 右侧编辑器，胶囊搜索框、标签 chip 条、分段式「编辑 / 预览」切换；列表与编辑器之间的分隔条可拖动调宽（双击复位，0.4.2 新增），窄窗口下自动收缩换行不裁剪
- **平铺速览列表**：无目录层级干扰，所有笔记按更新时间排列，相对时间（「3 小时前」）一目了然，悬停查看完整时间戳；**列表可直接拖拽排序、重要笔记一键置顶（0.4.0 新增）**
- **舒适阅读排版**：标题、列表符号、引用块色条、圆角代码块、斑马纹表格全部重新调校，明暗主题自适应；状态栏可调字号（小/中/大）与行宽（全宽/适中），长文阅读更舒服
- **沉浸编辑**：无边框大标题、无干扰正文区、停笔约 1 秒自动落盘，`Ctrl+S` 随时手动保存
- **标签配色（0.3.1 新增）**：同名标签固定同一颜色（色点 + 轻着色底），三处展示位置一致，扫一眼就能定位
- **紧凑模式（0.3.1 新增）**：头部一键切换「紧凑/舒适」，紧凑下列表只显示标题+时间，一屏翻倍

## 📌 功能

### 笔记管理

- **本地纯文本存储**：每篇一个 `.md`（YAML front matter 存元数据），外部编辑器改动即时可见
- **全文搜索 + 标签筛选**：标题 / 正文 / 标签联合检索，标签 chip 单击即筛选（单选：再击同一个取消，点另一个直接切换）；点击标签即自动打开该标签列表最上方的笔记（0.4.3 新增）；筛选某个标签时点「新建笔记」，新笔记自动挂上该标签
- **批量删除**：点右上「批量删除」进入多选模式，卡片勾选、支持全选，一键移入回收站
- **回收站（0.2.2 新增）**：删除不再直接销毁——笔记与附件原样移入库根目录 `.trash/`，保留 30 天；回收站视图内可单条恢复（回到删除前的目录）或彻底删除，也可一键清空，超期自动清理
- **自动保存**：停止输入约 1 秒自动落盘；切换笔记、返回聊天、关闭窗口前自动冲刷；保存失败静默重试，`Ctrl+S` 保留为手动立即保存

### 拖拽排序与置顶（0.4.0 新增）

- **拖拽排序**：按住列表里任意笔记卡片上下拖动，出现蓝色插入指示线，松手即完成排序；把笔记拖到置顶组里等于置顶，拖出来等于取消置顶，落点即所得
- **置顶**：卡片悬停出现的 📌 图钉一键置顶/取消；右键菜单也有「置顶 / 取消置顶」；置顶笔记成组固定在列表最上方，组内顺序同样可拖
- **不动笔记文件**：手动顺序与置顶登记存于库根目录 `layout.json`，与笔记 front matter 完全解耦——排序、置顶不刷新笔记的更新时间，不触发自动保存
- **新笔记插队可预期**：刚创建/新导入的笔记（还没手动排过序）显示在普通区最上方；一旦拖过一次，从此按你的手动顺序走
- **搜索时自动让位**：搜索/筛选结果按相关度排列，此时禁用拖拽（顺序是临时的），置顶标记照常显示
- **重命名不丢置顶**：文件名随标题改名（id 变化）时，置顶与排序登记自动迁移到新文件名
- **Markdown 渲染预览**：标题、粗体/斜体/删除线、行内代码、围栏代码块、链接与裸链、多级嵌套列表、任务列表 `- [ ]`、引用块、表格（含对齐）、分隔线；直接产出 React 元素、不解析 HTML，无注入风险

### 数学公式（0.5.0 新增）

- 四种写法全覆盖：行内 `$...$`、独立成行的 `$$...$$`（可跨行）、`\(...\)`、`\[...\]`，全部交给 **KaTeX** 排成真正的数学版式——分式、根式、上下标、极限、求和/积分号、矩阵、多行对齐都正常，截图里那种 `$\lim_{x\to x_0}\frac{f(x)}{\alpha(x)}=0$` 不再显示成源码
- 按需加载：正文里真的出现公式才去取 KaTeX（约 280 KB）与配套字体，纯文字笔记零额外开销；加载中先按源码显示，落地后自动替换，内容不丢
- 不误伤货币与代码：`价格 $5 和 $6` 不会吞成公式；`\$` 转义、行内代码里的 `$`、围栏代码块里的 `$` 一律保持原样
- 容错可见：公式写错时 KaTeX 以红色小字标出出错位置（`throwOnError:false`），整篇预览不会崩

### 标签系统（0.2.0 新增）

- **提前自定义标签**：标签条末尾「＋ 标签」输入即建，支持逗号批量（`面试题, 算法, 待整理`）；没人使用的标签也会常驻标签栏，方便先把体系搭好
- **一处删除、全局生效**：右键标签 chip 选「删除标签」，即从标签栏与所有携带它的笔记中一并移除
- **一键重命名（0.3.6 新增）**：右键标签 chip 选「重命名」，登记表 `tags.json` 与所有绑定笔记的 front matter 即时同步新名字，状态栏显示同步篇数
- **新建即归类（0.3.12 新增）**：标签筛选生效时点「新建笔记」，新笔记默认带上当前筛选的标签，写完保存直接归入该分类，不用再手动挂标签
- **持久化登记表**：自定义标签存于库根目录 `tags.json`，与笔记数据同进退；迁移库位置时自动带走

### 附件与导入

- **拖入即导入**：文本类（`.txt` `.md` `.py` `.json` `.csv`…）直接进正文；`.docx` `.xlsx` `.pptx` 原件存入 `files/` 并**零依赖抽取文本**（自解 ZIP + XML，无第三方库）写进正文，可搜索、可被 AI 引用；其他（PDF / 图片 / 压缩包）原样保存，双击交系统程序打开
- **右键附件**：用系统默认程序打开，或在资源管理器中定位
- **删除笔记连带清理附件**，不留垃圾文件

### 与对话打通

- **对话回写（writeback）**：带附件/文档的对话轮次末尾出现「存入随手笔记」按钮，AI 抽取候选知识点 → 勾选确认 → 写入；纯文字回答不触发，绝不打扰
- **侧栏入口**：左侧栏「随手笔记」一键进入全屏笔记面板，「‹ 聊天」随时返回

## 📦 安装

### 方式一：dsh 插件市场（推荐）

收录后打开 dsh 的 **设置 → 插件（插件市场）**，搜索 `dsh-hand-note` 或「随手笔记」一键安装。

### 方式二：dsh CLI

```bash
dsh plugin --profile <你的profile> add dsh-hand-note
```

### 方式三：从 GitHub 直接装

```bash
dsh plugin --profile <你的profile> add github:amd47802574/dsh-hand-note
```

### 方式四：手动 / 开发模式（Windows）

```bash
git clone https://github.com/amd47802574/dsh-hand-note.git
cd dsh-hand-note
# 把本目录链接（或复制）进 dsh profile 的 node_modules，并在 profile
# package.json 的 dependencies 与 dsh.profile.bundles 中登记 dsh-hand-note
# 安装/卸载前需彻底退出 dsh，否则文件被占用（EPERM）
```

> 从旧版 `dsh-knowledge-lite` 迁移：默认库已改为 `~/dsh随手笔记`；首次启动后在底部状态栏「库位置」选回 `E:/dsh-kb`（或任意位置），笔记、附件与标签会自动迁移过去。

## 🚀 快速上手

1. 打开左侧栏「随手笔记」，点右上 **＋ 新建笔记**
2. 填标题、写正文（Markdown），停笔即自动保存
3. 想分类？在标签栏点 **＋ 标签** 先建体系；编辑器里点 **＋ 标签** 按钮从列表点选，或输入新名字回车直接创建并挂上。先点某个标签筛选再新建，新笔记会自动挂上它
4. 带文档聊完后，点对话轮次末尾的 **存入随手笔记** 沉淀知识点
5. 想换库位置？点底部状态栏右侧的「库位置」文件夹胶囊，弹出系统文件夹选择窗口，选完自动迁移

## ⚙️ 配置

| 项 | 默认值 | 说明 |
|---|---|---|
| 笔记根目录 | `~/dsh随手笔记` | 所有笔记与附件的存储位置，可在底部状态栏随时更改（自动迁移）。设了 `DSH_HOME` 环境变量时为 `$DSH_HOME/dsh随手笔记` |
| 配置文件 | `~/dsh-hand-note.json` | 记住根目录设置，独立于插件目录与笔记库，profile 重置不丢失 |
| 自定义标签 | `<根目录>/tags.json` | 提前注册的标签登记表，可手工编辑 |
| 排序与置顶 | `<根目录>/layout.json` | 手动排序列表 + 置顶登记，可手工编辑 |

目录结构：

```
~/dsh随手笔记/
├── notes/          # 每篇笔记一个 .md（文件名即笔记 id）
│   └── 子目录/     # 磁盘文件夹即分类（可选）
├── files/          # 附件原文件（<id>--<原名>）
├── .trash/         # 回收站：删除的笔记保留 30 天（0.2.2 新增）
├── tags.json       # 自定义标签登记表
└── layout.json     # 手动排序 + 置顶登记（0.4.0 新增）
```

## 🏗️ 架构

| 文件 | 职责 |
|---|---|
| `lib/store.js` | 笔记存储：扫描（mtime 缓存）、增删改查、标签登记表、批量删标签、标签重命名（全局同步）、回收站（移入/恢复/彻底删除/30 天清理）、手动排序与置顶（layout.json） |
| `lib/index.js` | 宿主（Node）侧入口：webServer 路由（RPC + 静态资产）+ 令牌鉴权 + RPC 分发表 |
| `lib/assets/katex/` | 随插件打包的 KaTeX 运行时（`katex.min.js` + `katex.min.css` + 20 个 woff2 字体），由 `asset/*` 路由直发，不走 npm 依赖解析 |
| `lib/client.js` | 浏览器半侧 UI：面板、列表、编辑器、Markdown 渲染、自动保存 |
| `lib/attachments.js` | Office 文档零依赖文本抽取（ZIP + XML 手解，无第三方库） |
| `lib/writeback.js` | 对话回写：定位会话轮次、调用 LLM 抽取候选 |
| `lib/writeback-prompts.js` | 抽取提示词 |
| `lib/config.js` | 根目录配置读写与库迁移 |

安全设计：浏览器→宿主的 RPC 走 per-start 随机令牌（注入鉴权页）+ 同源/环回回退校验，常量时间比较；Markdown 渲染零 `innerHTML`，笔记内容无法向 shell 注入标记。唯一以 `innerHTML` 落地的是 KaTeX 自己生成的公式 DOM（`trust:false`，\href/\includegraphics 之类命令不生效，公式里带不进标记）。静态资产路由 `/_dsh/dsh-hand-note/asset/*` 只读插件自带的 `lib/assets` 目录：`resolve` 后用前缀比对拦路径穿越，目录外一律 404，不暴露任何笔记数据，也不参与令牌鉴权（`<link>`/`<script>`/字体请求无法附带自定义头）。

## ❓ FAQ

**Q：和原版 dsh-knowledge-lite 什么关系？**
A：由它 fork 并深度改造：界面全部重做、新增自定义标签管理（提前建标签 / 全局删标签）、列表改平铺速览；数据格式与默认库位置完全兼容。

**Q：同时装两个插件会冲突吗？**
A：会看到两个入口、两份相同的库（默认同根目录）。建议二选一。

**Q：默认库在哪里？**
A：用户主目录下的 `~/dsh随手笔记`（Windows 即 `C:\Users\<用户名>\dsh随手笔记`；设了 `DSH_HOME` 则在其下），任何机器开箱即用、不依赖某个盘符。想换位置点底部状态栏的「库位置」即可；改 `lib/config.js` 的 `DEFAULT_ROOT` 可换默认值。

**Q：外部编辑器改了 .md 会丢吗？**
A：存储层按 mtime 缓存，外部改动会被识别并展示；插件写入采用临时文件 + 原子重命名，不会写出半截文件。

**Q：删除笔记会丢吗？**
A：不会立即丢。删除会把 `.md` 移到库根目录的 `.trash/` 里，附件原样保留，30 天内在「回收站」视图里随时恢复（回到删除前的目录）；彻底删除或超期才真正清掉文件与附件。

**Q：删除标签会动我的笔记吗？**
A：只从笔记的 front matter 里移除该标签字段，正文与其他标签原样保留；删除即时生效并在状态栏显示影响篇数，删错了重新挂上即可。

**Q：拖拽排序 / 置顶会改动笔记文件吗？**
A：不会。顺序与置顶登记在库根目录 `layout.json` 里，与笔记 .md 完全解耦：不刷新更新时间、不触发自动保存；删掉 `layout.json` 即回到纯按更新时间排序。笔记重命名（文件名随标题变）时登记自动迁移，置顶不会丢。

**Q：重命名标签会动我的笔记吗？**
A：只改 front matter 里的标签名，正文与其他标签原样保留；登记表 `tags.json` 与所有绑定笔记即时同步，状态栏显示同步篇数。新名字与现有标签重名时直接报错，不动任何数据。

**Q：数学公式没渲染出来？**
A：先确认配对写对（行内两个 `$`、块级两个 `$$` 或 `\[...\]`），且 `$` 内侧紧贴内容（`$ x $` 这种带空格的不算公式，避免误伤货币写法）。KaTeX 运行时是首次出现公式时才从插件自身的 `asset/katex/*` 拉的，若被代理/扩展拦截会一直按源码显示——F12 看那条请求是否 404 或被 block，放行后重开面板（或重启 dsh）即重试。

- 细节：`mdHasMath` 预判避免无谓加载；未就绪/渲染失败降级为源码占位，不阻塞预览渲染；`\$` 转义、行内代码与围栏代码块里的 `$` 保持字面；货币写法（`$5`、`$6`）不误判为公式；公式落地后自动重排，无需刷新
